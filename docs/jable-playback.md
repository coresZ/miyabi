# Jable 在线播放接入设计

状态：设计稿。只接在线播放，不接刮削、发现、离线下载或 Emby。

## 边界

Jable 是 Cloudflare 后面的 HLS 站点。详情页按番号可定位，正片在 m3u8，分片和密钥有时效，并且要求站点 Referer。现有播放器能播 m3u8，但分片由浏览器自己请求。把站点地址直接交给播放器，分片没有 Referer，不能播。

因此接入只做三件事：

1. 用番号解析出一条 m3u8。
2. 由后端带 Referer 拉取并改写清单，同源转发分片和密钥。
3. 在现有播放页增加一个默认关闭的来源。

明确不做：

- 不作为刮削来源。资料仍由 FANZA、FC2、HEYZO、JavDB 提供，Jable 的标题和演员不写入、不覆盖。
- 不做站内热门、分类、搜索，也不把 Jable 影片灌进媒体库。
- 不写 `.strm`，不同步 Emby。签名地址会过期。
- 不提供任意 URL 代理。中继只接受本次解析出来、且域名在允许名单内的地址。
- 不绕过 Cloudflare。挑战页、验证码或空播放地址都返回「暂时不可用」。

## 播放流程

```text
播放页选择 Jable
        ↓
现有媒体库列表（仅有番号的影片）
        ↓
GET /api/jable/play?code=SSIS-001
        ↓
后端读取 https://jable.tv/videos/{code}/
        ↓
抽出唯一 m3u8，校验域名
        ↓
改写清单里的分片和密钥为同源地址
        ↓
现有 hls.js 播放 /api/jable/media?...
```

播放页不保存、不展示原始 CDN 地址。浏览器只访问 Miyabi。

## 接口

两个接口都挂在现有登录保护下，和 `/api/local/play`、`/api/playables` 一样。未登录返回现有 401。

### `GET /api/jable/play?code=`

按番号解析并返回改写后的主清单。

- `code` 先走现有番号规范化。空番号、无法规范化、或不像番号的输入直接 400，不请求站点。
- 详情地址只拼 `https://jable.tv/videos/{code}/`。不接受调用方传入 URL。
- 页面里没有唯一 m3u8、域名不在允许名单、或响应是挑战页，返回 404，文案为「暂时不可用」。网络失败返回可重试错误，不缓存成「不存在」。
- 成功时 `Content-Type: application/vnd.apple.mpegurl`，`Cache-Control: private, no-store`。

播放器拿到的地址就是这个接口。主清单里的变体、分片、密钥再指向媒体中继。

### `GET /api/jable/media?src=`

转发一条已允许的清单、分片或密钥。

- `src` 必须是本次解析链路里出现过的绝对 HTTPS 地址，主机在允许名单内。
- 允许名单先只含 `jable.tv` 及其播放时实际返回的 CDN 主机。实现时以录制样本确定主机，不把名单做成用户配置，也不接受任意主机。
- 清单响应要改写其中的 URI；媒体分片原样转发，保留 `Content-Type` 和范围响应。
- 上游要求的 `Referer: https://jable.tv/` 和固定浏览器 `User-Agent` 由后端附加。不转发浏览器带来的 Cookie、Authorization。
- 非法 `src` 返回 400，不发起上游请求。

中继不做磁盘缓存。签名过期由播放器按现有 HLS 错误显示，用户重新点选即可重新解析。

## 设置

在设置页「影片刮削」之后增加一节「在线播放」，不放进刮削来源列表。

- 一项开关：Jable。默认关闭。
- 说明：用番号在线播放。需要能访问站点，失败不影响本地和 115。
- 保存键：`playback.jable`，布尔值，走现有 settings 存取。
- 关闭时播放页不显示该来源；直接请求两个接口返回 404，避免关掉开关后旧页面继续拉流。

## 播放页

来源条在现有「本地 / 115 / 收藏」之后增加「Jable」。仅当开关打开时出现。

- 列表复用 `/api/playables?scope=local` 的影片身份，只保留有番号的条目。不新增 Jable 目录，也不按站点热门排序。
- 点选后播放地址为 `/api/jable/play?code={code}`。现有 `player-core.js` 看到 `m3u8` 路由或该接口路径时走 hls.js。接口路径没有 `.m3u8` 后缀，播放器需要认这条路径，不能只看扩展名。
- 解析失败时，该影片标记不可播，不清空当前正在播放的本地或 115 内容，除非用户点的就是当前项。
- 不增加画质选择。主清单有多档时选第一条可播放变体，后续再做选择。

## 模块

| 位置 | 职责 |
| --- | --- |
| `internal/jable` | 番号到详情页、抽出 m3u8、改写清单、校验主机。不依赖 Ent、任务或播放页 |
| `internal/api` | 登录保护下的两个只读接口，读取开关，调用 `internal/jable` |
| `web/src/features/player` | 来源开关打开时显示 Jable，并把番号播放地址交给现有播放器 |
| `web/src/features/settings` | 一个默认关闭的开关 |

`internal/jable` 不进入刮削来源注册，也不实现 `metadata.Source`。

## 失败

| 情况 | 结果 |
| --- | --- |
| 开关关闭 | 播放页无此来源；接口 404 |
| 番号无效 | 400，不访问站点 |
| 挑战页、无播放地址、域名不符 | 404「暂时不可用」，不缓存为永久缺失 |
| 上游超时或 5xx | 可重试错误 |
| 分片签名过期 | 播放器报错，重新点选再解析 |
| 本地或 115 播放 | 不经过这套接口 |

## 验证

- 解析器用录制的详情页 HTML 和 m3u8 文本测试。测试不请求 `jable.tv`。
- 覆盖：唯一 m3u8、多个地址时拒绝、允许名单外主机拒绝、清单 URI 被改写、非法 `src` 不发出上游请求。
- 播放页：开关关闭时没有 Jable；打开后点选使用 `/api/jable/play?code=`。
- 浏览器实测由用户完成：一部已知番号能播，解析失败时页面仍可切换本地或 115。
